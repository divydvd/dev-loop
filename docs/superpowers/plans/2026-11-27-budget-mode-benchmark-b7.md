# Budget Mode A/B Report and `B7-webhook-queue` Benchmark Plan

## Abstract
Live `copilot -p` runs on CLI `1.0.115-7` write AI Unit (`AIU`, where `1 AIU = 10^9 nanoAiu`) metrics to `--usage-output-file` instead of `events.jsonl`, and `scripts/run-benchmark.mjs` lacked a multi-domain task or `--baseline-budget-mode` / `--candidate-budget-mode` flags to reproduce Budget mode A/B evaluations.
This small-feature plan commits the sanitized `2026-11-27` Budget mode A/B benchmark report (`docs/benchmarks/2026-11-27-budget-mode-ab.md`) and extends `scripts/run-benchmark.mjs` with task `B7-webhook-queue`, Budget mode sandbox configuration, and `usage.json` telemetry fallback.
The expected result is deterministic zero-credit CI coverage of `O1`–`O11` webhook queue invariants, Budget mode sandbox setup, and `usage.json` cost extraction in under `130` production lines.
